### H-04 · `src/three/HeroScene.tsx:279–286` ↔ `src/three/PipelineScene.tsx:326–334` ↔ `src/three/SkillsOrb.tsx:219–227`

**Vấn đề:** Cùng một đoạn giải phóng tài nguyên WebGL (traverse → dispose geometry/material → dispose renderer → gỡ canvas) lặp 3 lần trong module `three/`.
**Phần khác nhau:** Hero dùng `if (m.geometry) m.geometry.dispose()`, hai file kia dùng `m.geometry?.dispose?.()`; SkillsOrb gỡ qua biến `c` (= `renderer.domElement`).
**Đề xuất:** tạo `src/three/dispose.ts`:

```diff
+import * as THREE from "three";
+
+/** Free every GPU resource the scene holds, then detach the canvas. */
+export function disposeScene(scene: THREE.Scene, renderer: THREE.WebGLRenderer, host: HTMLElement) {
+  scene.traverse((o) => {
+    const m = o as THREE.Mesh;
+    m.geometry?.dispose?.();
+    const mat = m.material as THREE.Material | THREE.Material[] | undefined;
+    if (Array.isArray(mat)) mat.forEach((x) => x.dispose());
+    else mat?.dispose();
+  });
+  renderer.dispose();
+  if (renderer.domElement.parentNode === host) host.removeChild(renderer.domElement);
+}
```

và ở mỗi scene thay khối trên bằng `disposeScene(scene, renderer, el);`.
**Rủi ro:** **cần đọc kỹ** — chạm thứ tự dispose WebGL (requirement §4.2). Dự án không có test → **Pha 2 sẽ tự bỏ qua mục này kể cả khi chọn "toàn bộ"**.
